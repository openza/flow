# Reviewing Pull Requests

Openza Flow is designed to answer one question quickly: what pull request work needs my attention?

## Main Views

| View | Purpose |
| --- | --- |
| **Review Requests** | Pull requests where GitHub has requested your review |
| **Created** | Open pull requests authored by you |
| **Recently Reviewed** | Pull requests you recently reviewed |
| **Recently Created** | Recent pull requests authored by you |

## Common Workflow

<Steps>
1. Start with **Review Requests** and clear anything waiting on you.
2. Use **Created** to check whether your PRs need follow-up.
3. Use search when you know the repository, author, or title you want.
4. Filter by organization when work and personal GitHub activity are mixed.
5. Open a PR on GitHub when you are ready to review, comment, approve, or merge.
</Steps>

<Aside type="note">
  V1 intentionally does not perform review actions inside Flow. GitHub remains the place for approving, commenting, requesting changes, merging, and editing PRs.
</Aside>

## Refresh

Use the refresh button for an immediate update. If background mode is enabled, Flow can keep refreshing and notify you when a new review request appears.
