# Notifications

Openza Flow can show Windows toast notifications when new review requests appear.

## Behavior

- Notifications are opt-in.
- The first load does not notify you about existing PRs.
- Later refreshes notify only when a newly seen review request appears.
- Toast clicks can focus Flow and open the relevant pull request where supported.

## Background Mode

By default, closing the window quits Openza Flow. If you enable **Run in background**, closing the window hides Flow to the tray and background refresh can continue.

The tray menu includes:

- Open
- Refresh
- Pause or resume notifications
- Exit

<Aside type="note">
  Background mode and Start with Windows are separate settings. Enable only the behavior you want.
</Aside>

## Troubleshooting

If notifications do not appear, check Windows notification settings, Focus Assist / Do Not Disturb, and the app's notification setting inside Flow.
