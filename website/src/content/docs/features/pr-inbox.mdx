# PR Dashboard

The dashboard groups pull request work into focused views so you can scan quickly and open GitHub only when you need to act.

## Review Requests

Shows open pull requests where your review is requested. This is the default work queue.

## Created Pull Requests

Shows open pull requests authored by you. Use this to track feedback and merge readiness.

## Recent Activity

The dashboard also keeps quick access to recently reviewed and recently created pull requests, so PRs do not disappear from view immediately after you act.

## Search and Organization Filter

Search is debounced so typing does not flood GitHub. Organization filtering helps focus on one workspace at a time and is remembered across sessions.

## Cache

Openza Flow caches default first-page data in the app's local data folder. Search and organization-filtered views are refreshed from GitHub so the results stay explicit to the filter you chose.
