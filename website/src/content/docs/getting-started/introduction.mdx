# Welcome to Openza Flow

Openza Flow is a Windows-native desktop app for staying on top of GitHub pull requests. It brings review requests, your created pull requests, recently reviewed work, recently created work, search, organization filtering, and notifications into one focused dashboard.

The active app is built with .NET 10, Windows App SDK, and WinUI 3. The earlier Flutter app is preserved for legacy history and old downloads, but new development targets the WinUI 3 version.

## Quick Start

1. [Install Openza Flow](/flow/getting-started/installation) on Windows.
2. [Sign in with GitHub](/flow/getting-started/github-token).
3. Use Review Requests first, then Created PRs to track your own work.

## What Flow Does Not Do

Openza Flow V1 does not approve, comment on, merge, or request changes from inside the app. It is a focused pull request dashboard that opens GitHub when you are ready to act.
