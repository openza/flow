# Installation

Openza Flow V1 is Windows-first and distributed through MSIX / Microsoft Store packaging.

## Requirements

- Windows 10 22H2 or newer, or Windows 11
- x64 PC for the first Store package
- GitHub account

## Microsoft Store

When the Store listing is live, install Openza Flow from Microsoft Store and launch it from the Start menu.

<Aside type="note">
  The Store package is the preferred release path because it provides trusted signing, clean install, automatic updates, and uninstall behavior.
</Aside>

## Developer Build

Use this path only if you are building from source.

<Steps>
1. Install Visual Studio 2026 Community or newer with the Windows App SDK / WinUI workload.

2. Install the .NET 10 SDK.

3. Clone the repository.

   ```powershell
   git clone https://github.com/openza/flow.git
   cd flow
   ```

4. Restore, test, and build.

   ```powershell
   dotnet restore src\Openza.Flow.Tests\Openza.Flow.Tests.csproj
   dotnet test src\Openza.Flow.Tests\Openza.Flow.Tests.csproj -c Release --no-restore
   dotnet restore src\Openza.Flow\Openza.Flow.csproj
   dotnet build src\Openza.Flow\Openza.Flow.csproj -c Release --no-restore
   ```

5. For packaged debugging in Visual Studio, select the `Package` debug profile and enable Deploy for `Openza.Flow` in Configuration Manager.
</Steps>
