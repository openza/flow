## Features

<CardGrid stagger>
  <Card title="Windows Native" icon="rocket">
    Built with WinUI 3 and Windows App SDK for a modern Windows 10 and Windows 11 experience.
  </Card>
  <Card title="PR Dashboard" icon="approve-check-circle">
    Track review requests, created PRs, recently reviewed work, and recently created PRs.
  </Card>
  <Card title="GitHub OAuth" icon="github">
    Sign in using GitHub device flow, with a Personal Access Token fallback when you need it.
  </Card>
  <Card title="Organization Focus" icon="setting">
    Filter pull requests by organization and keep that preference across sessions.
  </Card>
  <Card title="Windows Notifications" icon="bell">
    Optional background refresh can notify you when new review requests appear.
  </Card>
  <Card title="Open Source" icon="open-book">
    MIT licensed, transparent, and built without telemetry or analytics.
  </Card>
</CardGrid>
