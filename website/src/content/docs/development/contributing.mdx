# Contributing

Thanks for helping improve Openza Flow.

## Setup

<Steps>
1. Fork the repository on GitHub.
2. Clone your fork.
3. Create a focused branch.
4. Make changes in the WinUI app, core library, tests, or docs.
5. Run tests and build before opening a pull request.
</Steps>

```powershell
dotnet restore src\Openza.Flow.Tests\Openza.Flow.Tests.csproj
dotnet test src\Openza.Flow.Tests\Openza.Flow.Tests.csproj -c Release --no-restore
dotnet restore src\Openza.Flow\Openza.Flow.csproj
dotnet build src\Openza.Flow\Openza.Flow.csproj -c Release --no-restore
```

## Pull Request Guidelines

- Keep PRs focused on one feature or fix.
- Add tests when changing GitHub API logic, auth, cache, background refresh, or notification behavior.
- Include screenshots for UI changes.
- Do not commit access tokens, signing certificates, MSIX packages, `.msixupload` files, Visual Studio user files, or Partner Center private data.

<Aside type="tip">
  For feature ideas that change the workflow, open an issue first so the shape can be discussed before implementation.
</Aside>
