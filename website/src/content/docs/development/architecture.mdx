# Architecture

Openza Flow is split into a small WinUI app layer and a testable core library.

## Project Structure

```text
src/
  Openza.Flow/
    App.xaml
    MainWindow.xaml
    Services/
    ViewModels/
    Package.appxmanifest

  Openza.Flow.Core/
    Models/
    Services/

  Openza.Flow.Tests/
```

## Layers

| Layer | Responsibility |
| --- | --- |
| `Openza.Flow` | WinUI screens, Credential Locker integration, tray icon, settings, startup task, toasts, app lifecycle |
| `Openza.Flow.Core` | GitHub auth, GraphQL query building, DTO mapping, cache, background refresh decisions |
| `Openza.Flow.Tests` | Unit tests for auth parsing, query composition, mapping, cache, and refresh notification rules |

## GitHub Access

The app uses `HttpClient` and `System.Text.Json` for GitHub REST and GraphQL calls. Query builders and mappers live in the core project so they can be tested without launching WinUI.

## Storage

- Tokens: Windows Credential Locker
- Settings: app local settings
- Cache: JSON files in app local data

## Legacy Flutter App

The Flutter app is preserved in `legacy/flutter` and `legacy-flutter-v0.2.0`. It is not maintained side by side with the WinUI app.
